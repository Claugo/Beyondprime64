Source code

GitHub repositories

Both programs are published as open source under the MIT license. Each repository includes the C++ source, precompiled executables, input file format documentation, and usage instructions.

microprime_suffix
Segmented GC-60 sieve for prime window analysis beyond 10¹⁹. Two-window comparison, suffix analysis, six-panel charts. Benchmarked to 10²⁶.
github.com/Claugo/microprime-suffix
GC60-M30x3-suffix
Three-binary parallel architecture. Same deterministic output as microprime_suffix, ~30% faster. Reaches 10²⁶ in 53 minutes, 10²⁷ in 3.6 hours.
github.com/Claugo/GC60-M30x3-suffix
